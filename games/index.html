📚 Hướng dẫn sử dụng

  1. Bấm nút Tải File Mẫu bên dưới để lấy file Excel mẫu.
  2. Mở file Excel, điền câu hỏi vào NOI_DUNG và đáp án vào DAP_AN. (Cột SAI_1, SAI_2... dành cho câu trắc nghiệm nhiễu của Game Cờ Caro).
  3. Quay lại trang này, bấm Tải Lên File Của Bạn để nạp dữ liệu.
  4. Chọn 1 trong các game bên dưới và đưa lên máy chiếu cho học sinh chơi!
