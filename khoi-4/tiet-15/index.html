🎛️ Quy Trình Thực Hành: Mở Tệp – Bullets – Lưu Tệp

1️⃣ Mở tệp có sẵn (Hình 31)

Khởi động PowerPoint → Chọn File → Open → Tìm đúng thư mục → Nháy tệp Canh dep que huong → Bấm Open.

2️⃣ Chữ & Gạch đầu dòng (Hình 33, 34)

Chọn văn bản → Chỉnh phông, cỡ, màu chữ → Nháy nút Bullets (nhóm Paragraph) để tạo, đổi màu hoặc bỏ dấu đầu dòng.

3️⃣ Lưu tệp & Thoát an toàn

Nháy biểu tượng đĩa mềm 💾 Save để lưu lại thay đổi mới nhất → Nháy nút X để thoát phần mềm.

📌 MẸO NHANH TRÊN POWERPOINT

Muốn bỏ dấu gạch đầu dòng ở dòng nào, chỉ cần đặt con trỏ (hoặc bôi đen dòng đó) rồi nháy lại vào nút Bullets một lần nữa.
